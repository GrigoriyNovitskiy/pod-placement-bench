# RL-алгоритмы

Два алгоритма используют одну встроенную нейросеть:

| ID | Выбор размещения |
| --- | --- |
| `rl-top1` | План с максимальной оценкой нейросети. |
| `rl-topn-fitcount` | Top-N планов по оценке сети, затем выбор FitCount. |

## Запуск

Нужен JDK 25. Веса входят в дистрибутив, Python не требуется.

```sh
./gradlew build installDist
./placement-bench simulator
./placement-bench run --dataset /path/to/dataset --algorithm rl-top1
./placement-bench run --dataset /path/to/dataset --algorithm rl-topn-fitcount --param topN=20
./placement-bench algorithms rl-topn-fitcount
```

У Top-1 только параметр `model`: путь к своему JSON; пустое значение использует
встроенные веса. У Top-N также `topN` (20), `seed` (44), `fitCap` (10) и
`cacheRows` (64). Описания параметров доступны в CLI и при наведении в UI.

## Устройство

Общий `GreedyPlanner` строит допустимые планы с учётом ресурсов, фильтров,
NUMA, дисков, GPU и зависимостей. Нейросеть оценивает участников каждого плана;
их оценки суммируются. Сеть: 115 признаков → tanh(32) → одно число,
3745 параметров. Подготовка чисел: signed log1p и нормализация.

Встроенные веса, порядок признаков и параметры нормализации находятся в
[policy.json](../../src/main/resources/one/cloud/benchmark/algorithms/rl/policy.json).
Формат и размерности проверяются при загрузке, SHA выводится в результатах.

При `N=1` гибрид совпадает с Top-1; если N покрывает всех кандидатов на каждом
решении — с FitCount с теми же настройками. При наличии допустимого плана
запрос размещается. Миграций нет, удаления обрабатывает движок. Будущие запросы
и времена удаления модель не получает.

## Происхождение и результаты

Модель обучена на 8 подмножествах по 32 хоста из облаков 02/05/07/09:
20 эпох подражания FitCount и 12 PPO-итераций, seed 42, раздельные Adam и clipping.
Checkpoint после итерации 2 выбран по validation на облаках 04/06; test — 01/08/10.
Источник — snapshots с синтетическими операциями; GPU моделируются как devices20.
Код обучения в поставку не входит.

SHA-256 встроенной модели:
`1e680c943bcc08573af03a827179b6e587f18be8f77ea51cdaa0046c9bb35241`.

Полный dataset-08: 459 хостов, 28 620 событий с удалениями. Каталог 32,
fitCap 10, cacheRows 64, seed 42; один JVM fork, один прогрев и два измерения.
Mean — медиана средних задержек полных вызовов Engine.schedule.

| Способ | Pod | Shard | GPU-pod | Mean, мс |
| --- | ---: | ---: | ---: | ---: |
| FitCount | 14138 | 9728 | 133 | 4.276 |
| Random20 + FitCount | 14141 | 9741 | 146 | 0.893 |
| RL Top-1 | 14088 | 9725 | 130 | 1.803 |
| RL Top-20 + FitCount | 14118 | 9732 | 137 | 2.121 |

Top-1 быстрее FitCount в 2.37 раза с потерей 0.35% pod; гибрид — в 2.02 раза
с потерей 0.14%. Random20 здесь лучше обоих RL-вариантов. Это один сценарий
и seed, не гарантия качества на других облаках. CLI без `--catalogue-limit` использует
полный каталог, что может изменить решения гибрида и стоимость FitCount.
