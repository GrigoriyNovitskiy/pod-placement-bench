Модель GPU и ограничения

NVIDIA и Intel — разные ресурсные категории. Названий моделей GPU в формате нет.

В режиме devices20 устройства синтетические, по 20 долей. Дробный запрос меньше 1 GPU размещается на одном устройстве; запрос ≥1 требует целое число свободных устройств.

Фактические правила задаёт Java-движок. Экспорт не сохраняет исходную топологию MIG или схему совместного использования GPU.

При отказе UI сообщает, что алгоритм не разместил запрос. Без отдельной диагностики он не приписывает отказ конкретному ресурсу.
